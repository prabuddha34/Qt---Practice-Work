# 🖥️ Qt Widgets Practice

A collection of **Qt 6 Widgets** examples built using **C++** and **Qt Creator**. This repository contains small applications demonstrating commonly used Qt Widgets, layouts, and the **Signals & Slots** mechanism.

---

## 🚀 Technologies

- 💻 C++
- ⚡ Qt 6
- 🪟 Qt Widgets
- 🛠️ Qt Creator
- 📦 CMake

## 🎯 Mini Demonstrations

### ☑️ Checkbox Demo
- Detect checked items
- Display selected options

### 💰 Price Calculator
- Enter laptop price
- Select quantity using QSpinBox
- Calculate total automatically

### 🕒 Digital Clock
- Display live time
- Update every second using QTimer and QLCDNumber

### 🏦 Account Selector
- Select account type using QComboBox
- Update displayed selection

### 🎚️ Slider Demo
- Horizontal slider
- Display current slider value

### 📃 List Widget Demo
- Display a list of programming languages
- Customize fonts and colors

### 🔤 Font Selector
- Change the font of a QTextEdit using QFontComboBox

### 📊 Table Widget Demo
- Create rows and columns
- Add headers
- Insert table data

### 📅 Calendar Demo
- Display the selected date from QCalendarWidget
